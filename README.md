# Plantillas de trabajo de docencia de MAXCORP

Materiales organizados por curso: **ET403 / ET505 / ET203 / ET502**.

ET505 tiene la demostración resuelta y la plantilla de semana 7. Los otros cursos son espacios reservados; todavía no contienen actividades.

## Empezar desde una tablet o celular

1. Cree su propia cuenta en https://github.com/signup y confirme su correo. Conserve su contraseña.
2. Abra este repositorio e inicie sesión. Pulse **Use this template → Create a new repository**. Si no ve el botón, pruebe la vista de escritorio del navegador.
3. En **Owner** elija su propia cuenta. Use un nombre como `mi-plantilla-docencia`. Elija **Public** para usar GitHub Pages con GitHub Free. Pulse **Create repository**. Su copia es independiente de la del docente.
4. Entre a **Settings → Pages**. Elija **Deploy from a branch**, rama **main**, carpeta **/(root)** y **Save**. Este ajuste no se activa automáticamente al copiar una plantilla.
5. Espere a que GitHub termine la publicación. Abra la dirección que muestre Pages. No invente el enlace. Si aún no está lista, revise el estado en **Actions**.

## Editar y probar ET505

1. En SU repositorio abra **ET505 → plantilla → app.js**. Pulse el lápiz **Edit this file**; puede estar dentro del menú de opciones.
2. Busque `TODO 1`, `TODO 2` y `TODO 3`. Complete los cambios de la guía. Las funciones que muestran los mensajes ya están preparadas.
3. Pulse **Commit changes**, describa el cambio y guárdelo en `main`. Si elige otra rama, debe incorporar sus cambios a `main` para publicarlos.
4. Edite **ET505/plantilla/index.html** para personalizar el nombre, la actividad y el presupuesto visible. Edite **ET505/plantilla/README.md** para explicar sus aportes. Guarde cada cambio.
5. Abra su página de Pages → **ET505 → Abrir plantilla**. Espere a que termine la actualización y recargue. La vista de código de github.com no ejecuta la aplicación.
6. Mantenga dos pestañas: una para editar y otra para probar. En un teléfono, la vista horizontal o la opción Sitio de escritorio puede facilitar la edición.

No necesita instalar Node, usar Codespaces ni subir el ZIP desde el teléfono: **Use this template** copia los archivos ya extraídos.

## Para el docente

La demostración resuelta está en **ET505/demo**. Edite `ET505/demo/app.js` y `ET505/demo/index.html` para demostrar cambios desde su tablet. Su página se actualiza cuando GitHub completa la publicación. El presupuesto inicial es S/150.

Prueba válida: 10 unidades a S/15.00. Prueba de exceso: 10 unidades a S/15.01. Comprobar y Confirmar muestran errores rojos diferenciados; el último pedido válido se conserva.
